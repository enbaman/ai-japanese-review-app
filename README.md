# AI Japanese Review App

A personal project developed using PHP, MySQL, and JavaScript.

## Overview

This application allows users to review Japanese text and manage reviews.

## Features

* Random Japanese text display
* Text evaluation
* Comment submission
* Review history management
* Review editing and deletion
* Review statistics
* AI score and feedback display
* Suggested text improvements
* Dark mode
